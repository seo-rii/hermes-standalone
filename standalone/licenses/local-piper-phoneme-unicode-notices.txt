ucd-tools tables retain their original Unicode Character Database 11.0.0
semantics. The source build includes src/include/compat/wctype.h, which
remaps wide-character predicates to ucd-tools. These actual source macros
and unchanged packaged UCD functions are independently exercised by an
authoring-only compiled wrapper. Runtime classification and case tables
preserve those Unicode 11 source facts, not the host C library's locale or
Python's current Unicode version. No native executable payload is shipped.
