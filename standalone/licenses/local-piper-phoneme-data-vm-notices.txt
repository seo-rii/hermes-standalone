The runtime reads the original compiled dictionaries and phoneme data
included separately under assets/piper/espeak-ng-data. These are data files,
not native extensions. The interpreter executes the original phoneme
instruction data using Python code. Its test fixtures contain original
native observations only; no native library or executable is shipped.
