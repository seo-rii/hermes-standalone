The implementation preserves the original phoneme substitutions, regression,
stress promotion, insertion/linking, active table transitions, clause markers
and caller-owned retained output buffer. Native observations are independent
regression inputs and expected results, never a production phrase lookup.
All compiled pronunciation data remain original reviewed package resources.
No native library, external program or compiler is used at runtime or in
public tests. Source and observation hashes are retained in
local-piper-phoneme-list-provenance.json.
